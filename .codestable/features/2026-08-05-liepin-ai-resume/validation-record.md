# AI话术自动发简历验证记录

## 基线
- 服务：`http://127.0.0.1:8888`
- 测试前配置：18 个关键词、全国、`6$10`、AI 开启、上限 30、间隔 2-5 秒。
- 测试前状态：猎聘已登录，任务空闲。

## 修改命令与输入
- 临时配置输入：单关键词 `放疗设备客户服务工程师`、薪资 `0$100`、AI 开启、上限 1、间隔 0-0 秒。
- 启动：`POST /api/liepin/start`
- 确认：检测到 `pendingGreeting.aiAvailable=true` 后，`POST /api/liepin/confirm`，输入 `{"jobId":76783833,"action":"ai"}`。
- 恢复：按基线配置调用 `PUT /api/liepin/config`。

## 字面输出与退出码
- 启动输出：`{"success":true,"message":"猎聘任务启动成功","status":"started"}`，退出码 `0`。
- 确认输出：`{"success":true,"message":"已记录确认动作"}`，退出码 `0`。
- Java 回归：`BUILD SUCCESSFUL`，退出码 `0`。
- 恢复后配置校验：关键词 18 个、AI `1`、上限 `30`、间隔 `2-5` 秒，退出码 `0`。

## 页面证据
- 聊天窗口本人消息依次包含平台默认招呼、AI生成招呼语、`这是我的简历`。
- 简历消息卡片同时显示 `在线简历` 和 `附件简历`。
- 数据库岗位状态为 `delivered=1`。
