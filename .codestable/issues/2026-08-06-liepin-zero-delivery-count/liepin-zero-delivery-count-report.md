# 猎聘零成功计数 Issue Report

## 1. 问题现象

投递流程中，岗位卡片被扫描或进入发送前流程时就推进任务计数；当所有岗位因 JD、相关度、AI 话术、人工跳过或发送结果不确定而未成功发起聊天，服务仍发布：

`投递任务完成，共发起0个聊天`

这会把“任务结束”误读成“成功完成”，也会提前消耗单次投递上限。

## 2. 复现路径

1. 打开猎聘投递页并点击开始投递。
2. 让岗位在真正发送前被跳过，或让发送结果未被聊天窗口确认。
3. 观察任务完成消息和后续岗位扫描范围。

## 3. 期望行为

- 成功聊天数只由聊天窗口确认成功的发送结果累加。
- 跳过岗位、重复会话、缺 JD、无关岗位、AI 失败和不确定发送结果均不计数。
- 达到上限后停止继续扫描。
- 零成功完成时显示明确的未成功提示。
