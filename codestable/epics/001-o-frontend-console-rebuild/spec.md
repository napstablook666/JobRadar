# 前端控制台重构

## 这个 Epic 要改变什么

将 Next.js 配置控制台统一为深色优先的作战工作台：全站 Lucide 图标、响应式导航、平台配置/分析工作区，以及按需图表渲染。

## 为什么现在做

现有界面混用图标库、表情符号、重型玻璃效果和全量客户端组件；1440px 分析页与 375px 手机均出现全局横向溢出。

## 当前方案

保留现有路由、HTTP 接口、字段和动作。先重建应用壳与语义 token，再统一控件与平台页，最后收敛图表加载、动画和验证。

## 界面与交互变化

### 目标界面 / 流程

- 角色与入口：本机操作者从环境配置或任一招聘平台进入。
- 图示状态：目标

```text
桌面
[导航轨] [工作台头部: 配置 | 分析 | 状态 | 操作]
         [配置区 / 指标区 / 图表区 / 数据表]

移动
[顶部栏 | 当前平台 | 菜单]
[抽屉导航]
[单列内容；表格在自身容器内滚动]
```

- 交互与关键状态：桌面可折叠导航；手机抽屉可通过菜单、遮罩和 Escape 关闭；平台头部保持配置/分析路径可达。
- 稳定约束：页面本身不横向滚动；浮层不被内容容器裁切；键盘焦点和点击区与视觉层级一致。

## 架构考量

- 根布局保留为 Server Component，主题和导航状态收进最小客户端壳层。
- 图表只在分析视图进入可见区域后从本地依赖动态加载，移除 CDN 脚本注入。
- 动效只使用 transform 与 opacity；缩减动效时停止非必要效果。

## 质量约束与取舍

- 性能效率：配置页不加载图表模块；不保留持续运行的 WebGL 或大面积 backdrop-filter。
- 交互能力：375px、768px、1024px、1440px 均无页面级横向溢出；深浅主题和键盘路径完整可用。
- 可维护性：图标、图表、壳层和控件风格只保留一个来源。

## 当前推进

### epic 内直接推进

- 应用壳与设计 token：已替换全局布局、主题、导航和图标体系，并完成跨尺寸截图验证。
- 平台工作区：已统一配置/分析入口并补齐猎聘分析路由，现有请求和动作保持可用。
- 图表与渲染：已接入共享懒加载图表模块，移除 CDN 注入并完成页面渲染检查。

## 验证记录

- `pnpm lint` 通过，零错误与零警告。
- `pnpm build` 通过，静态路由包含 `/liepin/analysis`。
- 1440px：环境配置、Boss 分析、猎聘分析无页面横向溢出。
- 375px：环境配置与猎聘配置无页面横向溢出，头部动作组自动换行。
- 抽屉可通过菜单、遮罩和 Escape 关闭；深浅主题、配置/分析路径和缩减动效均已验证。

## 暂不推进范围

- 后端 API、投递策略、数据库结构和业务规则。
- WebGL/Three.js 主视觉。

## 关闭条件

- 所有前端图标来自 Lucide，界面无表情符号和 react-icons。
- 全部配置与分析入口可用，猎聘分析路由可访问。
- lint、生产构建、桌面/移动布局和缩减动效验证完成。
