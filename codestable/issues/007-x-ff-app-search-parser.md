# APP 搜索响应解析修复

## 做了什么

修复暂缓岗位重试在浏览器搜索响应结构变化时直接失败的问题；解析异常现在保留当前关键词，等待后续重试。

## 改了哪些

- `Liepin.java` — 支持多层响应包装、岗位列表字段变体、嵌套岗位 ID 和空列表；异常详情包含响应长度、顶层字段与解析原因。
- `LiepinSearchResponseTest.java` — 覆盖正常结构、变体结构、嵌套 ID、空列表和异常响应。
- `进度白板.md` — 记录本轮修复与验证结果。

## 怎么验证的

Java 全量 `190` 个测试通过；解析定向测试通过；补丁在隔离副本应用后 3 份文件哈希一致；隔离回滚恢复源码与白板基线，并移除新增测试文件。
