# 做了什么

启动猎聘投递时，先在搜索页设置自定义年薪范围，再处理岗位；断点续跑通过分页回到原页。

# 改了哪些

- 将本地月薪 K 范围换算为网页年薪万元输入。
- 按精确文本定位“薪资”“自定义”“确定”，同步捕获确认后的搜索响应。
- 响应结构、控件数量和数值回读失败时抛出明确异常。
- 保留本地月薪交集筛选，并更新猎聘配置页说明。

# 怎么验证

- `./gradlew.bat test` 通过。
- `pnpm lint` 通过。
- `pnpm build` 通过。
- 实测网页确认请求带 `salaryCode=7$12`；平台将 7.2 万下限归一为 7 万。

# 对 `codestable/` 的影响

无影响。
